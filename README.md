# Lavka_helper

**Удобное приложение для курьеров Яндекс Лавка**

Приложение помогает вести учёт смен, заказов и заработка в реальном времени.

## Возможности

- **Таймер смены** с анимированным прогресс-баром
- **Добавление заказов** вручную и через буфер обмена (из Яндекс Про)
- **Автоматический расчёт заработка** (почасовка + за заказ + чаевые + бонусы)
- **Учёт выплат** (завтра + среда)
- **Полная история смен** с возможностью редактирования
- **Статистика** за сегодня и общая
- Красивые анимации и удобный интерфейс
